## 安装

1. 解压下载的 ZIP 文件。
2. Edge 打开 `edge://extensions/`，Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 删除或停用旧版本插件。
5. 点击“加载已解压的扩展程序”，选择解压后的 `ethan-workorder-exporter` 文件夹。
6. 刷新 Ethan 网站页面。

## 页面按钮

### 待确认工单

完成网站筛选后点击，读取当前页工单列表并生成 6 列表格：

`运营人员｜公司名称｜操作人员｜完成时间｜服务简写｜待确认`

- 不输出表头。
- 按实际完成时间从早到晚自动排序。
- 日期自动转换成 `7月16日` 格式。
- 人员名称自动去除“运营-”“设计-”等前缀。
- 公司名称尽量读取省略号对应的完整名称。
- 第六列固定为“待确认”。
- 可在预览中修改单元格，然后直接粘贴到 Excel、WPS、飞书表格或腾讯文档。

### 待处理工单

完成网站筛选后点击，读取当前页每一行的：

`设计服务｜信息服务｜下单数量`

按“服务类型 × 下单数量”汇总，自动复制简写文本，例如：

`首页1主图14模板1替换1修改3`

- 同时读取设计服务和信息服务，空值自动忽略。
- 同一行中同一服务类型只统计一次，再乘以该行下单数量。
- 支持首页、简易主图、主图、详情、模板、替换、修改、新增、板块、轮播、海报、白底、场景、视频、标题、关键词、上架、属性等简写。
- 统计结果复制成功后，页面顶部会显示提示。
