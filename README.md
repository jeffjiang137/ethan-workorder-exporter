# Ethan 工单助手

**把重复的工单统计、商品素材收集和图片筛选，集中到一个浏览器插件。**

面向电商设计师、1688 运营及 Ethan 工单使用者的 Chrome / Edge 扩展。支持商品图片与视频下载、网页图片批量采集、长图拼接和工单统计。

[下载最新版](https://github.com/jeffjiang137/ethan-workorder-exporter/releases/latest) · [反馈问题](https://github.com/jeffjiang137/ethan-workorder-exporter/issues) · [历史更新](CHANGELOG.md)

> 如果它帮你省下了整理素材或统计工单的时间，欢迎点一个 ⭐ Star，让更多同行找到它。也欢迎带着实际页面和复现步骤反馈问题。

## 能帮你做什么

| 场景 | 功能 |
| --- | --- |
| 收集商品素材 | 下载 1688 商品主图、详情图、SKU 图片及页面可获取的视频 |
| 批量处理商品 | 粘贴商品链接启动下载队列；支持当前窗口多个商品标签页素材处理 |
| 整理店铺链接 | 获取当前页或店铺商品链接，复制、保存为文本，再交给下载队列 |
| 筛选网页图片 | 在页面内打开批量采集面板，扫描、滚动加载、筛选、预览和多选素材 |
| 制作参考长图 | 选择图片并拼接为长图，便于整理设计参考 |
| 保存素材 | 通过浏览器下载；检测到本机 Billfish 时可选择目标文件夹导入 |
| 检查图片文字 | 调用本地识别服务识别图片文字，并与可维护的词库匹配 |
| 统计 Ethan 工单 | 提取待确认工单，汇总待处理、处理中及今日完成数据，复制到表格或文本 |
| 下载后续更新 | 面板右上角检查 GitHub 最新正式版，有新版时下载 ZIP 更新包 |

**普通素材采集无需登录 Ethan。** 工单相关功能需要你已有 Ethan 网站访问权限；图片文字识别需要额外的本地服务。

## 快速安装

1. 到 [Releases](https://github.com/jeffjiang137/ethan-workorder-exporter/releases/latest) 下载 `ethan-workorder-exporter-v版本号.zip`。
2. 解压到一个固定目录。之后请保留该目录，浏览器会直接从这里加载插件。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」。
5. 选择**直接包含 `manifest.json` 的目录**，再将插件固定到工具栏。
6. 刷新已打开的商品页或 Ethan 页面，点击插件头像开始使用。

当前提供开发者模式安装包，未提供应用商店安装入口。

## 更新已安装的扩展（Windows）

点击插件面板右上角的更新按钮下载新版 ZIP，完整解压到临时文件夹，再双击里面的 `update-extension.cmd`。脚本会找到 Chrome 或 Edge 实际加载的 Ethan 目录，直接覆盖更新，再为找到的扩展 ID 注册图片置入 Photoshop 的本机组件。注册完成后，在扩展管理页点「重新加载」，再刷新正在使用的网页。

首次安装请先按上面的步骤加载扩展。需要补注册 Photoshop 组件时，可以再次双击更新包里的脚本。

发布时在项目目录运行 `python build-release.py`，将生成的 `ethan-workorder-exporter-v版本号.zip` 上传为同版本 GitHub Release 的附件。扩展的更新按钮按这个文件名查找附件。

## 三种常用工作流

### 下载商品素材

打开 1688 商品详情页，使用页面中的「商品图片下载」入口；或在插件面板粘贴商品链接，选择所需素材类型后开始下载。处理多个已打开商品页时，可使用「下载所有标签页」。

素材是否可下载、可取得何种清晰度，取决于网页实际提供的资源。页面未提供的原图、视频或 SKU 素材无法凭空补全。

### 收集网页参考图

在目标网页点击「批量采集当前页面图片」，扫描并筛选素材，预览后多选保存。懒加载页面可配合滚动加载；需要长图时选择图片后使用拼接功能。

未安装 Billfish 也可使用浏览器下载。Billfish 导入取决于本机程序及接口是否可用，本项目不是 Billfish 官方产品。

### 汇总工单

在 Ethan 网站完成筛选后，使用待确认、待处理 / 处理中或今日完成入口生成结果，再复制到 Excel、WPS 等工具。统计以页面实际加载的数据为准，多页列表请逐页确认。

## 更新方式

点击面板右上角「检查更新」。有新版时会下载 Release 中的 ZIP；没有新版时显示当前版本提示。

下载完成后，完整解压并双击包内的 `update-extension.cmd`。脚本会覆盖原插件目录中的对应文件并注册 Photoshop 图片置入组件。完成后，在扩展管理页点「重新加载」，再刷新使用中的网页。

## 图片文字识别与词库

识别功能依赖本机 `127.0.0.1:8866` 的文字识别服务，需启动鑫洋设计助手中的相应服务；该服务不包含在本仓库中。未安装服务时仍可使用独立的素材下载与工单功能。

词库匹配仅作人工复核参考：未命中不代表内容没有风险，命中也不代表已作出合规结论。识别结果受图片质量、字体和语言影响。

## 权限与使用边界

- 网页访问与脚本权限用于读取页面素材、显示采集面板及处理工单；跨站图片资源可能需要对应网站访问权限。
- 下载权限用于保存素材和更新包；存储权限用于保存操作员、设置及任务状态；剪贴板权限用于复制结果。
- 离屏页面用于素材打包与文字识别；本地网页采集还需在扩展详情中开启「允许访问文件网址」。
- 更新检查会连接 GitHub；文字识别会将待识别图片交给已配置的本地服务。
- 仅采集你有权访问和使用的素材，请遵守网站规则及版权要求。不绕过登录、验证码或访问限制。

## 常见问题

**更新后界面没变化？** 先在扩展管理页重新加载插件，再刷新目标网页，确认加载的是正确目录。

**某些图片或视频未被收集？** 尝试滚动页面并重新扫描。动态加载、跨域限制、失效链接及特殊播放器都可能影响结果。

**检查更新失败？** 检查到 GitHub 的网络连接，或直接前往 Releases 手动下载。

**识别提示本地服务未启动？** 启动本地识别服务后重试；普通下载不依赖它。

## 项目结构

- `popup.html` / `popup.js`：插件面板与操作入口
- `background.js`：后台调度、素材处理与下载
- `batch-collector/`：页面采集、筛选、预览与保存
- `linked-product-queue.js`：商品链接下载队列
- `image-word-check*.js` / `word-library.*`：文字识别接入与词库管理
- `update-check.js`：GitHub Release 更新检查
- `manifest.json`：扩展配置
